## Changes in this PR
1. [P0 accuracy] Finance syncs check FEC ids against the public crosswalk (api/_fec_crosswalk.js, new; api/_handlers/sync-rep-finances.js; api/_handlers/sync-senator-finances.js). Each run first loads legislators-current.json from unitedstates/congress-legislators, the dataset sync-repspace.js already reads. If a member's stored id is not on their id.fec list, the listed id for that chamber with FEC's latest cycle replaces it. If the crosswalk lists the member with no FEC id, a stored id is kept only when the FEC name has the same last name and a compatible first name; otherwise it is cleared, so the page shows no money rather than someone else's. Corrected members are synced first. The FEC search fallback now needs a compatible first name, and a near-miss last name is reported but never written. Every change is returned in the sync's JSON as `crosswalk.updates`.
2. [P3] api/seo.js header comment: the example member URL is now the pattern `/rep/<first>-<last>-<bioguide id>` instead of one member's page (backlog item 7).
